# ReaDrumXT 0.1.16

- Match MIDI controller pads using manual note assignments, individual MIDI Learn, or bank MIDI Learn.
- Save and select named controller mapping presets, with a remembered default for new projects.
- Keep saved projects independent of later preset edits, deletion, and default changes. Older projects retain their original note layout.
- Keep controller assignments attached to pad positions when moving samples or loading kits.
- Rename pads directly in the pad or sequencer lane context menu.
- Optionally name output tracks from loaded pads using **More → Auto-name outputs from pads**. This runs only when selected.
- Route a bank's sixteen pad positions to outputs 1–16 while preserving other banks and output settings.

## Updating

Save your projects, synchronize packages through ReaPack, and restart REAPER to load the updated MIDI effect and interface.

## Controller setup

Open **More → MIDI mapping…**, learn your controller's pads, enter a preset name, and choose **Save preset**. Choose **Use as default** to reuse that saved layout in new projects. Each project keeps its own mapping.
